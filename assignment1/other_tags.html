1. <p> Tag

Use: The <p> tag defines a paragraph. Browsers automatically add space before and after it.

This is one paragraph.

This is another, separate paragraph.

2. <br> Tag

Use: The <br> tag inserts a single line break (like pressing Enter). It has no closing tag.

Roses are red,
Violets are blue,
HTML is fun,
And so are you!

3. <hr> Tag

Use: The <hr> tag draws a horizontal line, often used to separate sections.

Above and below this line is content separated by <hr>.

See? A line was drawn above.

4. <pre> Tag

Use: The <pre> tag displays text exactly as written in the code — keeping spaces and line breaks (useful for code or poems).

    function greet() {
        console.log("Hello, World!");
    }
